# CodeAlpha Artificial Intelligence Internship Tasks

This repository contains the completed tasks for the CodeAlpha Artificial Intelligence Internship program.

## 📌 Tasks Completed
1. **Task 1: Language Translation Tool** (`Language_Translation_Tool.ipynb`) - Multilingual translation using `deep-translator`.
2. **Task 2: Chatbot for FAQs** (`Chatbot_For_FAQs.ipynb`) - Conversational retrieval chatbot using Scikit-Learn TF-IDF and Cosine Similarity.
3. **Task 4: Object Detection and Tracking** (`Object_Detection_and_Tracking.ipynb`) - Real-time tracking pipeline using YOLOv8 and ByteTrack.
